# 🛍️ AURA — Premium E-Commerce Platform

A high-end, modern architectural e-commerce web application built with **React**, **Vite**, **TailwindCSS**, **Framer Motion**, and **Lenis Smooth Scroll**. Designed with Apple-style glassmorphism aesthetics, dynamic dark/light themes, and rich interactive features.

---

## ✨ Features Breakdown

### 🔐 User Authentication (Register & Login)
- **Global Auth Context**: Persistent user session using `localStorage`.
- **Interactive Auth Modal**: Pop-up sign-in and sign-up with password visibility toggles and real-time form validation.
- **Dedicated Auth Pages**: Custom `/login` and `/register` views with demo credential auto-fill.
- **User Dashboard**: Profile details management, address updates, order tracking, and security credentials updates.

### 🌊 Smooth Animations & UX
- **Lenis Inertia Smooth Scroll**: Silky momentum scrolling across all pages.
- **Route Page Transitions**: Framer Motion `AnimatePresence` with smooth fade & slide-up effects.
- **Confetti Celebrations**: Order confirmation celebration animations.

### 🛒 Complete E-Commerce Workflow
- **Product Catalog & Search**: Instant modal search with title, category, and price filtering.
- **Interactive Shopping Cart**: Dynamic quantity management and total calculations.
- **Wishlist & Compare**: Save favorite items and side-by-side product specification comparisons.
- **Multi-Step Checkout**: Shipping address, payment method selection, order review, and instant receipt generation.

---

## 🛠️ Tech Stack

- **Frontend Framework**: React 18 + Vite 5
- **Styling**: TailwindCSS 3 + Custom Glassmorphism Utilities
- **Animations**: Framer Motion 11 + Lenis 1.3
- **Icons**: Lucide React
- **State Management**: React Context API (Auth, Cart, Wishlist, Compare, Theme, Toast, Recently Viewed)

## 🚀 Quick Start Guide

### 1. Clone the Repository
```bash
git clone https://github.com/lipp13/AURA-Premium-E-Commerce.git
cd AURA-Premium-E-Commerce
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
